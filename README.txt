PUBLISH
1. Create a PUBLIC GitHub repository named anuproyas-privacy-policy (or choose another name and update URLs accordingly).
2. Extract this ZIP and upload all files/folders to the repository root. Keep index.html in the root and keep the assets folder intact.
3. In the repository, open Settings > Pages. Choose Deploy from a branch, branch main, folder /(root), then Save. GitHub documents this publishing flow here: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
4. After deployment, test the main page and all three policy links. Expected URL pattern: https://YOUR-GITHUB-USERNAME.github.io/anuproyas-privacy-policy/
5. In the Blogger footer, point Privacy Policy to the published index.html URL. Add Terms & Conditions, Parents Consent and Refund Policy links if desired; use target="_blank" rel="noopener noreferrer" to open each in a new tab. Replace placeholder URL with your real GitHub Pages URL after publishing.

IMPORTANT REVIEW BEFORE PUBLICATION
- The new logo is included and used on the three newly created policy pages; the privacy page brand block is also updated where its original markup matched.
- The policy text is a draft template, not legal advice. Check every statement against your real practices and payment/course offers. In particular verify contact email/address, age/parent-consent workflow, data collection and retention, cookies/analytics, payment provider, cancellation timing and refund handling. Consider an Indian lawyer's review before relying on these terms.
- “Owner-favoring” provisions are drafted to protect content, accounts, payment integrity and operational flexibility, but preserve non-waivable consumer and child-protection rights. No wording can guarantee that a term is enforceable.
- GitHub Pages content is publicly accessible. Do not upload student data, passwords, private records or other confidential files.
- This package does not modify Blogger or publish anything automatically.
